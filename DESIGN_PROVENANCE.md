# Handbook design provenance

The handbook follows the current Louchi Storybook from the RaidGuild brand guide. It uses the generated semantic tokens, Ubuntu body and Ubuntu Mono utility fonts, Venture Beyond display fonts, and `BrandAction` CTA styles from `@raidguild/brand-system` `0.1.0-dev.sha6e3ed06` (brand main revision `6e3ed06241e9b282bf24afff3dcfb525796a4ce4`). The immutable package archive is pinned locally at `vendor/raidguild-brand-system-0.1.0-dev.sha6e3ed06.tgz`. It was built from the clean brand commit using `npm run publish:package-dev`; its SHA-512 is `sha512-rMwUdXPpOCOn9uo6C6QXhqoulnJPgS3+U4zxupu/t08C+5Gb5pvHV+U51xXnK4s7ZDYCNxDiAhdtfqxmtjixhw==`, matching the generated package manifest. The package includes three Archivo-derived Latin subset WOFF2 variable fonts, their SIL Open Font License 1.1, and checksums. It contains no Last Duel webfonts.

`src/css/custom.css` imports that package and maps its Louchi semantics to Docusaurus/Infima. Docusaurus controls `data-theme`, so the CSS adapter mirrors the package's current Louchi Night values under `html[data-theme=dark][data-brand-reign=louchi]`. A short head script sets the Louchi reign before first paint. Keep the adapter aligned with `dist/tokens.css` when updating the package pin.

The two-line homepage heading uses Venture Beyond Retalic Extended above native Venture Beyond Extended italic below, both at weight 900 and width 125%, with no synthesized faces. Ordinary documentation headings remain Ubuntu for reading. Last Duel was removed from the public `static/` tree after its embedded metadata identified it as a Eurostile-derived private font. The older Grinder Refined files remain inactive historical assets; metadata checks did not identify Eurostile. Neither family is registered in active CSS.

The homepage retains its three handbook routes, illustrations, and navigation. It uses the package's `BrandAction` component and CTA CSS while the docs retain readable Ubuntu typography and Docusaurus search and controls.

Sources: [Storybook](https://brand-storybook-production.up.railway.app/), [brand package manifest](https://raidguild-brand-guide-production.up.railway.app/packages/brand-system.json), [merged brand source](https://github.com/raid-guild/brand/tree/6e3ed06241e9b282bf24afff3dcfb525796a4ce4), and [authoritative website branch](https://github.com/raid-guild/website/tree/review/venture-beyond-redesign).

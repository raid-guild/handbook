# Discord Navigation

RaidGuild’s Discord is organized by purpose. Channel names change over time, so this guide focuses on the durable category map and the kind of work that belongs in each space.

| Category | Purpose |
| --- | --- |
| **Castle Walls** | Entry, lightweight onboarding instructions, and next steps. |
| **Town Square** | Public conversation, community chat, and memes. |
| **Guild HQ** | High-level member conversation. |
| **Governance** | Proposal announcements, RIP discussion, deliberation, and governance. |
| **Cohort** | Current cohort participants and hosts. |
| **Agency** | Hunts and business development, Cleric resources, client submissions, availability, and Raid operations. Raider Roundtable and Raider Roundup voice spaces live here. |
| **Raids** | Internal coordination for active client engagements. |
| **Camps** | Shared engagement spaces where the client is in the room. |
| **Knowledge** | Keeper of Knowledge stewardship and knowledge operations. |
| **Brand** | Brand Steward work and brand-system coordination. |
| **Infrastructure** | Infrastructure Maestro work, systems, and Guild tooling. |
| **Valhalla** | Archive and staging for stale Raids, Camps, and other channels before deletion. |

## Raids and Camps

The distinction matters:

- A **Raid** channel is internal. Use it for party coordination, candid delivery discussion, and information intended for Guild participants.
- A **Camp** includes the client. Treat it as a professional shared workspace and keep internal-only discussion in the corresponding Raid.

Respect client confidentiality in both spaces and confirm the audience before posting sensitive information.

## Finding the Right Place

Start in Castle Walls if you are new. For active work, follow the category purpose and any pinned instructions. If you are unsure, ask in the most relevant visible community space instead of cross-posting the same message across several channels.

# Connect with the Guild

Use these current surfaces to follow RaidGuild, join the conversation, and find the latest Guild writing.

| Surface | What You’ll Find |
| --- | --- |
| [Portal](https://portal.raidguild.org) | Profiles, sessions, cohort interest, newsletter, blog posts, and Guild updates. |
| [Discord](https://discord.gg/rGFpfQf) | Community conversation, onboarding, governance discussion, and Raid coordination. |
| [GitHub](https://github.com/raid-guild/) | Open-source projects, RIPs, code, and collaboration. |
| [X / Twitter](https://x.com/RaidGuild) | News and public updates from the main Guild account. |
| [Raid Guild Ish](https://x.com/RaidGuildIsh) | The Guild’s agent account. |
| [LinkedIn](https://www.linkedin.com/company/raid-guild/) | Professional updates, partnerships, and Guild work. |

## Legacy Archives

RaidGuild’s [Substack](https://raidguild.substack.com/) and [Medium](https://medium.com/raid-guild) preserve older writing. They are useful archives, but Portal is the current publishing destination.

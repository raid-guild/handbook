# Grinder webfont provenance

The three Grinder Refined WOFF2 cuts were copied from the canonical RaidGuild brand guide's `public/brand-fonts/louchi` directory for the Louchi handbook. The source guide records that Louchi supplied the files and the project owner reports rights were obtained. This is a record of that report, not an independent license verification or a redistribution grant.

These first-party site assets stay outside the reusable `@raidguild/brand-system` package. The package provides openly licensed Afacad Flux as its display fallback. The handbook uses Grinder Refined Regular, Italic and native Retalic at weight 400.

# Louchi display font provenance

Active handbook display typography comes from the pinned `@raidguild/brand-system` package: Venture Beyond Latin subsets, derived from Archivo 2.001 under SIL Open Font License 1.1. Source, license, and checksums are in the package.

The six Last Duel WOFF2 files were removed from the public `static/` tree after the brand audit identified them as Eurostile-derived private fonts. The older Grinder Refined files remain inactive historical assets; their embedded metadata was checked separately and did not identify Eurostile. No Last Duel or Grinder face is registered in active CSS.
